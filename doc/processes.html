How to create dynamic tables from CSV files

Standard Markdown tables, as shown in the Quarto Markdown Guide, work well for small static datasets. However, scientific datasets often contain dozens of rows, numerical measurements across different physical units, LaTeX expressions, and literature references. To handle these cases, this template includes a custom dynamic-tables filter that reads external .csv files and renders interactive tables powered by Tabulator.

Note

CSV files follow standard RFC-4180 formatting, meaning fields or headers containing commas can be enclosed in double quotes (e.g., "Energy, $E$"). File paths in src are resolved relative to the project root, the filter directory, or the current .qmd page.

Quick Table Insertion

To display a CSV file with default interactive settings, write a standalone paragraph starting with !dynamic-table: followed by the path to the file:

!dynamic-table: data/measurements.csv

This automatically generates an interactive table with a live search bar, clickable column sorting, pagination (15 rows per page), and automatic detection of numeric versus text columns.

Customizing Tables and Columns

For full control over table behavior and individual columns, use a fenced ::: {.dynamic-table} block. Inside the block, lines starting with # are treated as comments and ignored during rendering.

Global Table Options

Global options are written as key: value pairs at the top of the ::: {.dynamic-table} block:

::: {.dynamic-table}
src: data/measurements.csv
searchable: true
sortable: true
per-page: 20
:::
  • src: Path to the input .csv file (required).
  • searchable: Displays a live full-row search box above the table (true or false, default true).
  • sortable: Enables or disables sorting across all columns (true or false, default true).
  • per-page: Sets the initial number of rows displayed per page (default 15, with a built-in selector for 10, 15, 25, and 50 rows).

Column Headers, Types, and Sorting

Individual columns are configured using col N:, where N is the 0-indexed column position (col 0: refers to the first column, col 1: to the second, and so on). Multiple properties for the same column are separated by commas:

::: {.dynamic-table}
src: data/measurements.csv
col 0: header="Particle Name", string
col 1: header="Mass, $m$", number
col 2: header="Notes", unsortable
:::
  • header=...: Overrides the column title from the CSV header row. Enclose the title in quotes if it contains commas.
  • number / string: Overrides automatic column type detection to enforce numeric or alphabetical sorting (empty cells are always placed at the bottom).
  • sortable / unsortable: Overrides the global sortable setting for that specific column.

Dropdown Filters and Unit Conversions

Columns with categorical values or physical quantities can include interactive controls directly in the column header:

::: {.dynamic-table}
src: data/measurements.csv
col 0: dropdown
col 1: header="Energy Scale", units(GeV: 1, MeV: 1e3, TeV: 1e-3)
:::
  • dropdown: Adds a dropdown menu in the column header populated automatically with all unique values present in that column.
  • units(Unit1: factor1, Unit2: factor2, ...): Adds a unit selector to the column header. The first unit listed is active by default; selecting another unit multiplies every numeric value in the column by its corresponding conversion factor and formats extreme magnitudes in scientific notation.

LaTeX Math Formatting

Columns containing mathematical symbols or scientific numbers can be typeset using MathJax or KaTeX:

::: {.dynamic-table}
src: data/measurements.csv
col 0: header=$E_{\text{LIV}}^{(1)}$, latex
col 1: header="Upper Bound", latexnum, units(GeV: 1, TeV: 1e-3)
:::
  • latex: Renders LaTeX expressions (enclosed in $ ... $) inside both the column header and text cells.
  • latexnum: Typesets numeric cells—including scientific notation such as 1.2e-16 rendered as \(1.2 \times 10^{-16}\)—in math mode, updating automatically whenever the user switches units.

Automated INSPIRE-HEP Citations

A column tagged with inspire automatically links INSPIRE-HEP citation keys to a live bibliography rendered directly underneath the table:

::: {.dynamic-table}
src: data/bounds.csv
col 3: header="References", inspire, unsortable
:::

In the CSV file, cells in an inspire column should contain valid INSPIRE-HEP TeX keys (e.g., Gotz:2014vza). Multiple keys in the same cell can be separated by commas or semicolons (e.g., Cao:2021tat, Lang:2018yog).

During site compilation, the filter automatically:

  1. Queries the INSPIRE-HEP database for every unique citation key in the table.
  2. Formats the bibliography entries using the project’s CSL citation style and renders clickable [N] CitationKey links inside the table cells.
  3. Synchronizes the reference list below the table in real time so that only citations belonging to currently visible rows (after searching, filtering, or changing pages) are displayed.

Complete Example

Given a CSV file stored at data/bounds.csv:

Messenger,Effect,Bound,Reference
Gamma rays,Birefringence,1.0e-16,Gotz:2014vza
Gamma rays,Time delays,9.02,"LHAASO:2021opi, Cao:2021tat"

The following block combines dropdown filtering, unit scaling, LaTeX math formatting, and automated INSPIRE-HEP references:

::: {.dynamic-table}
src: data/bounds.csv
searchable: true
per-page: 10

# Column rules (0-indexed)
col 0: header="Messenger", dropdown
col 1: header="Effect", dropdown
col 2: header=$E_{\text{LIV}}^{(1)}$, latexnum, units(GeV: 1, TeV: 1e-3, Planck units: 8.19e-20)
col 3: header="References", inspire, unsortable
:::
