How to create dynamic plots

Static figures, as shown in the Quarto Markdown Guide, work well for fixed illustrations. For interactive scientific plots requiring zoomable 2D/3D canvases, analytical curve evaluation, tabular data overlays, LaTeX math labels, or animated parameter sweeps, this template provides a custom dynamic-plots filter powered by Plotly.

Defining Curves and Plotting a Canvas

Dynamic plots separate curve definitions from the plot canvas. Definition blocks (::: {.plot-function id="..."} or ::: {.plot-file id="..."}) register mathematical expressions or data series without rendering anything on their own; a ::: {.dynamic-plot} block then renders one or more registered IDs onto a single interactive canvas:

::: {.plot-function id="wave-sin"}
expr: sin(2 * x) * exp(-0.2 * x)
label: $e^{-0.2x}\sin(2x)$
xrange: [0, 8]
:::

::: {.plot-function id="circle-eq"}
expr: (x - 4)^2 + y^2 = 0.64
label: $(x - 4)^2 + y^2 = 0.8^2$
xrange: [0, 8]
yrange: [-1.2, 1.2]
color: crimson
:::

::: {.dynamic-plot}
curves: wave-sin, circle-eq
xlabel: $x$
ylabel: $y(x)$
:::

Block Configuration

All plot blocks are configured using key: value pairs inside fenced divs. Every .plot-function and .plot-file block requires a unique id attribute so it can be referenced in curves:.

Analytical Functions

Use ::: {.plot-function id="..."} to evaluate analytical expressions. Expressions support +, -, *, /, ^, implicit multiplication (2x, x sin(x)), constants (pi, e), and standard functions (sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, exp, log, ln, log10, log2, sqrt, abs, sign, floor, ceil, min, max):

  • expr: Mathematical expression (required). Whether = is present determines how the expression is evaluated:
    • Explicit (no =): Defines \(y = f(x)\) in 2D (using x) or \(z = f(x, y)\) in 3D (using x and y). Explicit expressions cannot contain z. 2D explicit curves sample along xrange only and automatically resample when zooming or panning.
    • Implicit (contains one =): Defines a 2D contour \(f(x, y) = g(x, y)\) (using x and y) or a 3D isosurface \(f(x, y, z) = g(x, y, z)\) (using x, y, and z). Because implicit equations are solved on a grid, they use sampling bounds along every active variable (xrange and yrange in 2D; xrange, yrange, and zrange in 3D), and mode and smooth are ignored.
  • xrange, yrange, zrange: Sampling domain [min, max] (min < max) along each axis (default: the canvas range if set, otherwise the co-plotted file extent, or [-10, 10]).
  • points: Sample resolution per axis, integer \(\ge 2\) (defaults: 100 for 2D explicit, 60 per axis for 2D implicit and 3D explicit, 25 per axis for 3D implicit).
  • label: Legend title, supporting inline LaTeX math (default: the block’s id).
  • color: Trace or surface color, passed directly as any valid CSS/Plotly color string (default: automatic colorway).
  • mode: Drawing style for explicit 2D curves (lines, markers, or lines+markers, default lines).
  • smooth: Enables spline interpolation between sample points on explicit 2D curves (true or false, default true).

Data Files

Use ::: {.plot-file id="..."} to plot numeric columns from .csv (comma-separated) or whitespace/tab-delimited text files (blank lines and comment lines starting with #, %, or // are ignored automatically):

  • src: Path to the input data file (required).
  • skip: Number of leading non-comment header rows to ignore, integer \(\ge 0\) (default 0).
  • x: Column expression for the horizontal axis using 0-based column tokens (c0, c1, c2, …) and any supported math operators, constants, or functions (required).
  • y: Vertical-axis column expression in standard mode (e.g., c1 or sqrt(c1^2 + c2^2)), or the sweep column selection when param is set (required).
  • z: Column expression for the third axis in 3D scatter/line traces (e.g., c2). Cannot be combined with param.
  • label: Legend title, supporting inline LaTeX math (default: the block’s id).
  • color: Trace color, passed directly as any valid CSS/Plotly color string (default: automatic colorway).
  • mode: Drawing style (lines, markers, or lines+markers, default lines+markers).
  • smooth: Enables spline interpolation between points on 2D line traces (true or false, default false).
  • Parameter sweep keys (enabled when param is provided; param-label and transform require param):
    • param: Numeric parameter values mapped one-to-one onto the columns selected by y. Set y to an ascending column range (c1..c7) or an explicit comma-separated list (c1, c3, c5, c7), and specify param either as a uniform range start..end (0..3, which interpolates linearly across at least 2 columns) or as a matching comma-separated list (0.0, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0).
    • param-label: Label displayed next to the active parameter value above the slider, supporting inline LaTeX math (default Parameter).
    • transform: Optional mathematical expression applied to every sweep column value before plotting. Inside transform, y refers to the active sweep column’s value in that row, and any column token (c0, c1, …) from the same row may also be referenced (for example, transform: y^2 to plot squared amplitude, or transform: y / c1 to normalize against c1).
::: {.plot-file id="damped-data"}
src: data/example-plot-damped.csv
skip: 1
x: c0
y: c1
label: Measured amplitude
mode: markers
color: #ff7f0e
:::

::: {.plot-function id="damped-model"}
expr: exp(-0.35 * x) * cos(2 * x)
label: $e^{-0.35t}\cos(2t)$
color: #1f77b4
:::

::: {.dynamic-plot}
curves: damped-data, damped-model
xlabel: Time $t$ [s]
ylabel: Amplitude $A(t)$ [m]
:::

Plot Canvas

The ::: {.dynamic-plot} block mounts the responsive Plotly canvas and configures axes and interactive controls:

  • curves: Comma-separated list of .plot-function and/or .plot-file IDs to display together (required). All curves in a plot must share the same dimensionality (all 2D or all 3D), with at most one parameter-sweep curve per canvas.
  • xlabel, ylabel, zlabel: Axis titles, supporting inline LaTeX math ($ ... $, \( ... \)). In 3D scenes, axes default to x, y, and z.
  • xscale, yscale, zscale: Axis scaling (linear or log, default linear).
  • xrange, yrange, zrange: Initial visible axis bounds formatted as [min, max] (min < max; bounds must be strictly positive when the corresponding axis uses log scale).
  • width, height: Canvas dimensions in pixels, integer \(\ge 200\). height defaults to 400; when width is omitted, the canvas automatically adapts to the available container width.
  • legend: Shows or hides the collapsible right-hand legend sidebar with per-curve visibility checkboxes (true or false, default true; when false, no legend is shown).
  • play: Adds a Play/Pause animation toggle button next to the parameter slider (true or false, default false). Valid only when curves includes a parameter-sweep curve.

Animated Parameter Sweeps

Combining sweep options in .plot-file with play: true in .dynamic-plot creates an interactive slider plot:

::: {.plot-file id="wave-sweep"}
src: data/example-plot-sweep.csv
x: c0
y: c1..c7
param: 0..3
param-label: $t$ [s]
label: Wave amplitude
smooth: true
:::

::: {.dynamic-plot}
curves: wave-sweep
xlabel: $x$ [m]
ylabel: $\psi(x, t)$
play: true
:::
